# Public assets

## Hero background video (optional but recommended)

The homepage hero is wired to play a fullscreen construction background video.
Until you add the file, it shows a polished animated fallback (a slow
"Ken Burns" zoom over a concrete texture), so the hero looks great either way.

To enable the video, drop your file(s) here:

- `public/hero.mp4`  ← required (H.264 MP4, ~1080p, 8–15s loop, no audio)
- `public/hero.webm` ← optional, smaller/faster for modern browsers

Tips for a premium look:
- Keep it short and seamless (a slow pan over a renovation / craftsmanship shot).
- Compress it (aim for < 5 MB) so it loads fast — it's muted + autoplay + loop.
- Free, license-friendly stock footage: Pexels Videos, Coverr, Mixkit.

No code changes are needed — the hero auto-detects the file and fades it in.
